# Security Policy

## Supported versions

Security fixes are released for the latest minor version only.

| Version | Supported |
| --- | --- |
| 0.1.x | ✅ |

## Reporting a vulnerability

Please **do not** report security vulnerabilities in public issues.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/mdnishat27/go-mapper/security/advisories/new) instead. Include a description of the problem, the affected versions and, if possible, a code sample that reproduces it.

You can expect an initial response within 7 days. Once the problem is confirmed, a fix will be released as soon as possible and credited to you in the release notes unless you prefer otherwise.
